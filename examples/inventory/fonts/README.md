# Demo font subset

`fusion-pixel-demo.woff2` is a 522-glyph subset of **Fusion Pixel 12px Proportional SC**, generated from the demo's static text so the first paint stays at ~18KB.

The full font remains in [`assets/fonts/FusionPixel-12px-SC.woff2`](../../../assets/fonts/FusionPixel-12px-SC.woff2). Both are distributed under the SIL Open Font License 1.1; see [`OFL-FusionPixel.txt`](../../../assets/fonts/OFL-FusionPixel.txt).
