01

Foundation

基础原则

黑是画布，橙是信号。界面大多数时候保持沉默，只在需要行动、确认或警告时点亮橙色；点阵字体提供骨架，让每一像素都有落点。

01

Black first

背景接近纯黑。层级由 1px 线、留白和字号建立，而不是一层层浅灰面板。黑色让橙色拥有电压。

02

Ember is a signal

橙色是稀缺资源：主行动、当前状态、关键数字。能不用就不用；用一次，就要让它说了算。

03

Pixels, not curves

0 圆角、1–2px 硬边、点阵字形、阶梯动效。任何柔化——模糊、光晕、缓动曲线——都是对风格的稀释。

02

Color

色彩

调色板只有五个角色：黑、面板黑、奶油白、灰、橙。再加一个只在破坏性操作中出现的警报红。

Contrast rule

橙色上永远使用黑字。奶油白在橙底上只有 2.8:1，禁止使用。

Integer sizes only

像素字只在设计尺寸的整数倍上清晰。Fusion 12 → 12 / 24 / 36；Silkscreen 8 → 8 / 16 / 24。不要写 13、14、15px。

No faux bold

中文只有 400 一个字重。强调用颜色、字号和间距，不要合成粗体——那会把像素糊成一团。

Antialiasing off

正文与 UI 关闭灰度抗锯齿（-webkit-font-smoothing: none），大号 Doto 保留抗锯齿，让圆点保持圆。

One primary

整屏只有一个橙色实心按钮。次级动作使用描边或纯文字。

Numbers are loud

关键指标用 Doto，大、圆、不可忽视；解释文字退回 Fusion 与灰色。

Structure before color

所有分区先由 1px 线和留白建立，橙色只是最后一步的点睛。

07

Motion

动效

动效是继电器，不是棉花糖。用 steps() 模拟档位切换，90–320ms，只动颜色、位移与透明度。

No bounce

没有回弹、没有弹簧、没有 scale(1.1)。像素世界的反馈是开关，不是果冻。

No blur

不淡入光晕，不做毛玻璃。出现就出现，消失就消失。

Reduced motion

尊重 prefers-reduced-motion：关闭 marquee、闪烁与所有过渡，状态依然清晰。

08

Rules

边界

风格不是加法，是拒绝。下面四组对比，是这套系统最容易被破坏的地方。

Do / 01Signal
EMBER OPS12:07

一个界面，一个主行动。橙色按钮是唯一的亮点。

橙色只给主行动。其余动作让位。
Don't / 01Overload
EMBER OPS12:07

每个按钮都是橙色，就没有按钮是重要的。

橙色通胀：所有东西都在喊，等于没人说话。
Do / 02Hard edge
0 RADIUS
直角、2px 线、硬投影。边缘就是态度。
Don't / 02Soft UI
20 RADIUS
圆角 + 柔影会立刻把像素语言稀释成 SaaS 模板。
Do / 03Hierarchy
Signal 点阵标题配像素正文，信息层级一眼可读。
Doto 负责标题，Fusion 负责正文。
Don't / 03Pixel body
用 Doto 排正文，每个字母都变成一排点，读三行就累。这就是为什么它只能做标题。
点阵标题字不能承担长文本。
Do / 04Steps
状态切换像继电器：两档，干脆。
Don't / 04Ease bounce
400MS · EASE-IN-OUT · SCALE(1.08) · BLUR(8PX)

Loud.
