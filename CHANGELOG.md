# Changelog

## [Unreleased]

- Added `examples/inventory/`: Parts Depot, a working household component inventory demo with a narrow icon rail, scan receiving, album archive, inventory / BOM, pick queue, inbound / outbound, materials, soldering jobs, history, CSV/JSON export and localStorage persistence.
- Demo UI uses a 18KB Fusion Pixel subset for fast first paint; the full font remains available in `assets/fonts/`.

## [1.0.0] — 2026-11-19

- Initial public release of the Ember Pixel design system.
- `SKILL.md`, `AGENTS.md` and `prompt.md` adapters for Agent Skills, AGENTS.md tools, and chat-only agents.
- Full component library (`assets/ember.css`) and eight-chapter visual reference (`assets/styleguide.html`).
- Offline Doto / Silkscreen / Fusion Pixel fonts (OFL 1.1), with a 19KB subset for the hosted guide.
- GitHub Pages deployment at <https://seaison.github.io/ember-pixel/>.
- Data visualization rules, skeleton, action menu, tooltip and pagination patterns.
- Accessibility fixes: ember-surface focus rings, keyboard-scrollable tables, inert illustrative demos, reduced-motion sequence.
- MIT license, Open Graph/favicon metadata, branded 404, and CI checks for docs and the font subset.
